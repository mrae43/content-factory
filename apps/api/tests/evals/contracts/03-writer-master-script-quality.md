# Writer's Desk — eval contract (3.1 Master Script Quality)

## What this eval guards
The master script must be coherent, directive-faithful, evidence-grounded,
appropriately dense, and audience-appropriate. A weak script propagates
bad content to every downstream format.

## Assertions
- LLM judge scores 5 dimensions 1–5: narrative coherence, directive fidelity,
  evidence grounding, claim density, audience fit
- All five dimensions: ≥ 3.5
- Any single dimension < 3.0: hard failure

## Failure modes covered
F-W1
